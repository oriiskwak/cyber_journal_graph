# 발표용 1초 타임라인

동일 평가에서 TP 최고 점수 사례인 `abnormal_BU2FfjTqGY8`와 TN 최저 점수 사례인 `normal_qsHWozaXnnw`를 선택했다. 각 영상에서 정수 초마다 로컬 원본 프레임을 캡처했다. 공개 그림에는 검토한 화면 문구 영역만 잘라 남겼다. 원본의 채팅 계정·연락처가 나타날 수 있는 본문 영역, 영상 속 사람·차량이 나타날 수 있는 장면과 소형 자막 영역은 캡처 이미지에 포함시키지 않았다. 생성기는 검토한 입력의 SHA-256을 확인한다.

- **화면 문구**는 공개 영역에서 읽힌 짧은 발췌다.
- **허용 객체**는 원본 시청 후 공개 가능한 일반 범주만 적었다. 사기 영상의 채팅 UI와 메시지 목록은 화면을 잘라내기 전의 사람이 검토한 관찰이다. 이 목록에는 사용자명이나 연락처가 없다.
- **TEMPO** 칸이 있는 시점은 모델이 실제로 점수를 기록한 프레임과 일치한다. 캡처는 발표용 발췌이며, 당시 모델은 영상 프레임을 448×448로 변환해 사용했다. 점수가 없는 시점은 표시용 캡처다. 추론에 쓰인 객체별 기여도는 확인할 수 없다.
