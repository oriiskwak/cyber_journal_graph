# 공식 투자사기 기준 그래프 파일럿

이 폴더는 영상 사건을 공식 기관이 설명한 투자사기 수법과 연결하기 위한 작은 기준 그래프다.
현재 범위는 `투자 리딩방·유명인 사칭 투자사기`로 제한한다.

## 원칙

- 공식 자료에 명시된 행동 조합만 패턴으로 만든다.
- 하나의 단서만으로 사기를 확정하지 않는다.
- `지지`, `반박`, `미확인`을 구분한다.
- 모든 패턴과 조건은 원문 위치와 URL을 가진다.
- 교육, 경고, 공식 상품 설명, 내부 참여는 정상 맥락 후보로 별도 저장한다.
- 이 파일럿은 법률상 범죄 확정기가 아니라 공식 수법과 영상 관찰의 대응 도구다.

## 파일

- `sources.json`: 공식 자료 목록과 사용할 원문 위치
- `schema.json`: 노드, 관계, 대응 상태 정의
- `patterns_seed.json`: 사람이 검토하기 전의 초기 패턴 초안

## 다음 단계

1. `patterns_seed.json`의 각 요소가 출처 위치에서 실제로 확인되는지 검토한다.
2. 기존 영상 사건 유형과 패턴 요소 사이의 대응표를 만든다.
3. 영상 10편에서 `지지/반박/미확인` 대응을 자동 생성한다.
4. 생성된 대응만 사람이 확인한다.
5. 대응 포함/제거 조건으로 LLM 점수 변화를 측정한다.

## 자동 후보 대응 실행

```bash
cd /home/dg/cyber_graph
.venv/bin/python experiments/match_official_patterns.py
```

결과는 `experiments/official_pattern_matches_dev.json`에 저장된다. 이 단계는 CPU만 사용하며
LLM API나 GPU가 필요 없다. 결과의 `candidate`는 검토 후보라는 뜻이며 사기 판정이 아니다.
