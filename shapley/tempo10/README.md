## 파일과 검산

- [TEMPO 점수 기여도 JSON](tempo_score_shapley.json)
- [Qwen3-8B 관찰 기여도 JSON](qwen3_observation_shapley.json)
- [영상별 4개 시간 구간 비교 CSV](tempo10_shapley_comparison.csv)
- [Qwen3-8B 조합 점수 CSV](qwen3_coalition_scores.csv)

TEMPO 계산 입력은 [발표 사례의 프레임 점수](../../run/presentation_cases.json),
8B 입력의 출처는 [마스킹된 관찰 JSON](../../graph/temporal_observations.json)이다.
두 계산은 영상별 저장 시점을 순서대로 정렬한 뒤 관찰 수를 기준으로 연속된 네 구간
B1~B4로 나눴다. 8B 입력에는 해당 구간의 관찰 요약, 기록된 화면 문구와
허용 객체를 포함했다. 객체로는 주식 그래프를 주식 차트, 가격 표시를 가격 라벨로
정규화했다. 새 객체 탐지나 TEMPO 72B 재분류는 수행하지 않았다.

조합 점수 CSV의 mask는 B1=1, B2=2, B3=4, B4=8의 비트 합이다.
영상별 0~15 점수를 [정확 Shapley 함수](../experiments/analyze_shapley_31.py)에
넣으면 8B 기여도를 재계산할 수 있다. 모든 영상에서 기여도의 합이
전체 점수와 빈 입력 점수의 차이와 일치함을 확인했다.
입력 시간 구간 40개와 모델 조합 점수 160개를 검증했다.
